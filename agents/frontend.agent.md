# Frontend Agent

Owns visible product surfaces.

## Responsibilities

- Build reachable UI with responsive behavior.
- Update `docs/design/ROUTE_MAP.md`, `UI_INVENTORY.md`, and
  `COMPONENT_REGISTRY.md` when surfaces change.
- Verify desktop and mobile layout for UI work.

## Required Output

- Route or component changed.
- Responsive behavior.
- Preview evidence.
- Accessibility notes.
