# Repo Audit Skill

Use this before meaningful edits.

## Steps

1. Read `AGENTS.md`, `README.md`, and `package.json`.
2. Run `git status --short --branch`.
3. Map routes, components, APIs, data files, auth, middleware, tests, docs, and
   receipts.
4. Identify existing patterns and likely affected files.
5. State files that must not be touched.
6. Produce repo map, risk tier, test plan, and rollback plan.
