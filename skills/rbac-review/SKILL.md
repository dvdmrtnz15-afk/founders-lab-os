# RBAC Review Skill

Use for auth, roles, permissions, protected resources, or tenant boundaries.

## Steps

1. Read `SECURITY.md` and `docs/security/RBAC_POLICY.md`.
2. Identify resource, action, role, ownership rule, and tenant boundary.
3. Check for bypass paths.
4. Confirm tests cover unauthorized, wrong-role, and owner-boundary cases.
5. Escalate elevated-risk changes.
