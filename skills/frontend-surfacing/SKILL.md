# Frontend Surfacing Skill

Use when a feature needs to be visible to users.

## Steps

1. Check `docs/design/ROUTE_MAP.md` and `UI_INVENTORY.md`.
2. Identify the route, component, and workflow where the feature belongs.
3. Reuse existing UI patterns.
4. Verify desktop and mobile behavior.
5. Update route map, UI inventory, and component registry.
