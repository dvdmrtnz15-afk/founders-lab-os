# Release Checklist

- [ ] Product intent and acceptance criteria are clear.
- [ ] Architecture impact is documented.
- [ ] UI/admin/API surfacing is documented.
- [ ] Data and migration impact is documented.
- [ ] RBAC/security review is complete.
- [ ] `pnpm format:check` passes.
- [ ] `pnpm lint` passes.
- [ ] `pnpm build` passes.
- [ ] Mobile preview checked for UI changes.
- [ ] Vercel preview checked before production.
- [ ] Rollback plan documented.
- [ ] Release receipt written.
