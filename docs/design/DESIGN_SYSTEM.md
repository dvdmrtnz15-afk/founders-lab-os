# Design System

FounderLab OS should feel like a professional builder cockpit: dense,
scannable, restrained, and action-oriented.

## Principles

- Prefer tool surfaces over marketing sections.
- Keep controls compact and predictable.
- Use visible state for gates, checks, previews, and approvals.
- Preserve mobile usability for the founder's phone QA loop.

## Current Visual Language

- Slate shell with emerald state accents.
- Compact cards and panels with `rounded-md`.
- Monospace labels for system state and commands.
- Dashboard-style sections for planning, preview, terminal, and release control.
