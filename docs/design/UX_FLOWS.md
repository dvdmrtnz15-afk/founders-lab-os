# UX Flows

## Governed Noesis Run

```txt
Open command center
  -> start governed run
  -> define objective and canonical state
  -> select warrant level and uncertainty
  -> scope capability lease
  -> attach and classify evidence
  -> inspect live allow / verify / block decision
  -> isolate only the blocker when needed
  -> record local dry-run receipt
  -> lease auto-revokes
  -> export workspace or receipt
```

## Resume or Transfer a Run

```txt
Open harness
  -> load validated browser-local workspace
  -> continue editing
  -> export versioned JSON
  -> import on another browser
  -> reject the file if strict schema validation fails
```

## Mobile QA Flow

```txt
pnpm dev:phone
  -> open LAN URL on iPhone
  -> verify decision rail appears before the editor
  -> verify import, export, reset, editing, and receipt actions remain available
  -> verify there is no horizontal overflow
  -> capture issue evidence
  -> fix before release handoff
```
