# Incident Response

## Immediate Steps

1. Stop the risky workflow.
2. Preserve evidence without exposing secrets.
3. Identify affected files, systems, users, and credentials.
4. Rotate exposed credentials if needed.
5. Patch the issue.
6. Run verification.
7. Write an incident receipt.

## Escalation

Escalate secrets, auth, production data, payments, customer impact, or deploy
pipeline compromise to human review immediately.
