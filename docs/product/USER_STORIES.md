# User Stories

- As a founder, I want agents to map the repo before editing so they do not
  duplicate or break existing work.
- As a founder, I want every feature to identify its UI or admin surface so
  backend work does not become invisible.
- As a reviewer, I want implementation receipts so I can see intent, risk,
  files changed, tests run, and rollback path.
- As an agent, I want role-specific instructions so I can behave like the right
  specialist for the task.
- As an operator, I want release readiness checks so production changes remain
  gated and reversible.
