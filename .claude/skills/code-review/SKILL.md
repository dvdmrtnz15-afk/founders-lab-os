# Code Review Skill

Use this skill to audit code before continuing development.

Review:

1. Correctness
2. Type safety
3. Next.js conventions
4. Security
5. Performance
6. UX clarity
7. Mobile behavior
8. Maintainability
9. Test/build confidence
10. Reversibility

Output:

- Critical issues
- Important issues
- Nice-to-have improvements
- Suggested patch plan
- Commands to run
