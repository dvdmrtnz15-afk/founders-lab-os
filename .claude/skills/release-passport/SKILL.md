# Release Passport Skill

Use this before deployment, demo, investor review, or major handoff.

Include:

1. What changed
2. Why it changed
3. Files changed
4. Commands run
5. Build result
6. Known risks
7. Rollback plan
8. User-facing impact
9. Production blockers
10. Approval status

Hard rule:

Do not deploy. Produce the passport only unless explicitly approved.
